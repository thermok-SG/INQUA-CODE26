# INQUA Coding Workshop 2026

## Landlab workshop notebooks

1. `intro_landlab/00_setup_and_orientation.ipynb` — short JupyterHub check.
2. `intro_landlab/01_landlab_fundamentals.ipynb` — core introductory lesson
   with optional fast-finisher exercises.
3. Choose one advanced track:
   - `advanced_landlab/02A_advanced_landscape_evolution.ipynb`
   - `advanced_landlab/02B_advanced_event_hydrology.ipynb`
4. `advanced_landlab/03_project_launch.ipynb` — scope a short project.

Completed instructor notebooks are stored under
`advanced_landlab/instructor/`. They should be kept available to facilitators
for hints and recovery rather than used as the default participant copies.

The notebooks use the local teaching datasets in `data/` and are intended to
run on the preset workshop JupyterHub.
